# sensory_motor_reconfiguration_in_aging
Code used for data acquisition and data analyses in the study:

Ribeiro, Calder-Travis, Canário, Castelo-Branco & Donner (2026). Impaired Sensory-motor Reconfiguration and Pupil-linked Arousal in Aging. bioRxiv. https://doi.org/10.64898/2026.06.01.729265

Code is written for MATLAB and depends on:

	eeglab functions - https://sccn.ucsd.edu/eeglab/index.php

	limo_eeg - eeglab plugin - https://github.com/LIMO-EEG-Toolbox/limo_meeg

	jbfill - https://www.mathworks.com/matlabcentral/fileexchange/13188-shade-area-between-two-curves


Behavioral task scripts run on MATLAB and depend on:

	Psychophysics Toolbox Version 3 - http://psychtoolbox.org/

Scripts required for the behavioral task hierarchical decision-making were adapted from the scripts by and used for:
Ruud L. van den Brink, Keno Hagena, Niklas Wilming, Peter R. Murphy, Christian Büchel, Tobias H. Donner,
Flexible sensory-motor mapping rules manifest in correlated variability of stimulus and action codes across the brain,
Neuron, Volume 111, Issue 4, 2023, Pages 571-584.e9, ISSN 0896-6273
https://doi.org/10.1016/j.neuron.2022.11.009.


Submodule SR-switches-behav points to code used for the computational modelling of behavioral data.
